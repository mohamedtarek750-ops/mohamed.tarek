# محمد طارق | كورسات واستشارات التسويق

موقع شخصي باللغة العربية يعرض نبذة عن محمد طارق، ومؤهلاته، والكورسات والاستشارات.

## الملفات
- `index.html`: الصفحة والتنسيق والتفاعلات.
- `assets/mohamed-tarek.jpg`: الصورة الشخصية.
- `assets/mohamed-tarek-logo.png`: اللوجو الأصلي؛ تُعرض النسخة الأساسية منه داخل الهيدر باستخدام CSS.

الموقع HTML/CSS/JavaScript ولا يحتاج إلى تثبيت مكتبات أو خطوة بناء. شغّله من مجلد المستودع باستخدام أي خادم ملفات ثابتة.

## النشر
الملفات جاهزة للاستضافة من جذر الفرع `main`. رفع الملفات لا يفعّل GitHub Pages تلقائيًا.

## تفاصيل لم تُستكمل
- أسماء البرامج ومواعيدها وأسعارها.
- وسيلة التواصل المباشرة والحجز.
- أسماء الجهات المانحة للمؤهلات.

زر الاستفسار يجهّز رسالة محليًا للنسخ، ولا يرسل الرسائل أو يخزّن البيانات. الصورة الشخصية الأصلية منخفضة الدقة ويمكن استبدالها بنسخة أعلى جودة بنفس اسم الملف.
